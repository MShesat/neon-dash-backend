# Neon Dash Cloud Backend (24/7 Music Proxy)

Servidor en la nube gratuito y permanente 24/7 para el juego **Neon Dash**.

### Características:
- **Sin PC encendida**: Corre en la nube de forma continua.
- **Emulación Metrolist / NewPipe**: Utiliza el cliente interno móvil `ANDROID` e `IOS` para sortear los bloqueos de IP de centros de datos de YouTube.
- **Música Completa**: Filtra automáticamente pistas menores a 60 segundos o mayores a 6 minutos para evitar previews y podcasts.
- **Soporte de Streaming con Rango (HTTP 206)**: Permite carga progresiva y visualización de espectro de audio en tiempo real.

### Cómo usar en Neon Dash:
1. Copia la URL de este Space (ejemplo: `https://TU_USUARIO-neon-dash-backend.hf.space`).
2. Entra a Neon Dash: https://neon-dash-proxy-shesat.vercel.app/
3. Haz clic en el icono de música 🎵.
4. Pega la URL en la barra **Túnel / Proxy Nube** y pulsa **CONECTAR**.
